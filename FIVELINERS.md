## Share with SSA colleagues — BrickSight Genie Code demo

🎬 I put together a Genie Code demo for data engineers — replay-in-browser, ~8 min: https://lbruand-db.github.io/genie-code-for-dataeng-demo/
🧱 Premise is BrickSight (a fictional toy-brick data co.) — three prompts in one conversation: explore the catalog, build a retirement-risk ML model, package the learnings as a skill file.
✨ The kicker: Genie Code picks `set_complexity_score` over `num_parts`, filters `is_spare`, and surfaces `ip_dependency_flag` — all driven by Unity Catalog descriptions, never from the prompt.
⏸️ Every ★ proof point autopauses so I can narrate live; voiceover script and screen cues are in `SPECS/DEMOSCRIPT.md` in the repo.
🚀 Already ran it with Capgemini — happy to share what landed and what I'd tweak next time; steal-and-adapt encouraged.
